# Тесля: авторизация на этап разработки (COPY fix)

Подтверждаю отдельную авторизацию на development-этап для исправления предполагаемой ошибки `COPY`.

## Границы этапа
Разрешено:
- восстановить SSH host-key trust для GitHub;
- создать отдельную task branch от `main` в repo `ai-da-secretary-sandbox-deploy`;
- внести минимальное исправление Dockerfile/compose-путей для устранения build-blocker;
- выполнить локальные проверки сборки и QA этого изменения;
- подготовить diff и отчёт.

Не разрешено на этом этапе:
- деплой на сервер;
- создание/редактирование `.env` на сервере;
- изменения системного Nginx;
- выпуск/перевыпуск TLS;
- `reset --hard` без отдельного согласования и явной проверки состояния.

## Результат, который нужен
1. Название task branch.
2. Список изменённых файлов.
3. Команды проверки и их результат (exit code).
4. Краткий QA-вывод: READY/NOT READY именно для build-fix.
5. Ссылка на PR (без merge), если push разрешён и выполнен.
